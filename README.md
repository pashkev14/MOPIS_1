# MOPIS_1 — Движок исполнения бизнес-процессов (Задание 3-1-1)

Программная система описания и исполнения бизнес-процессов над объектами предметной области на основе конфигурируемых YAML-моделей.

* **Дисциплина:** Модели объектов и процессов информационных систем (ЛЭТИ)
* **Вариант:** Вариант 1 — Включение нового комплектующего в справочник
* **Механизм объектной модели:** Наследование параметров классов (`parent` и переопределение параметров)
* **Стек:** Java 25 (OpenJDK), Maven, Jackson YAML/JSON, JUnit 6

## Структура проекта
- `config/` — YAML-конфигурации классов, объектов, ролей и шаблона процесса
- `docs/` — текст задания (`task_3-1-1.md`), спецификация и UML-диаграммы (`spec.md`)
- `logs/` — выходной журнал обработки команд в формате JSONL (`audit.jsonl`)
- `src/main/java/` — исходный код движка (`Type Object`, `FSM`, `Interpreter`, `Command`, `AuditLog`)
- `src/test/java/` — автоматические тесты (JUnit 6)
- `.opencode/skills/` — инструкции специализированных агентов (`architect`, `developer`, `tester-qa`, `debugger`)
- `AGENTS.md` — правила работы агентов в репозитории
- `opencode.jsonc` — конфигурация OpenCode v2 (провайдер RouterAI и политики безопасности)

## Сборка и запуск проекта (Java 25, Maven)
- **Сборка:** `mvn clean compile`
- **Запуск демонстрации:** `mvn exec:java`
- **Запуск тестов:** `mvn test`

## Настройка и безопасный запуск OpenCode v2 (v2.2.5+)
OpenCode запускается напрямую в системе без Docker, в изолированном режиме прав доступа (`opencode.jsonc`):
1. Убедитесь, что установлена версия OpenCode `2.2.5` или новее:
   ```bash
   opencode --version
   ```
2. Задайте переменную окружения с ключом от [RouterAI](https://routerai.ru):
   * **Linux / macOS:**
     ```bash
     export ROUTERAI_API_KEY="ваш_ключ_routerai"
     ```
   * **Windows (PowerShell):**
     ```powershell
     \$env:ROUTERAI_API_KEY="ваш_ключ_routerai"
     ```
3. Запустите OpenCode из корневой папки репозитория `MOPIS_1`:
   ```bash
   opencode
   ```
